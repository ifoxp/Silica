# Silica

Відомості про комп'ютер, живі датчики, тести продуктивності й тест стабільності для
Windows — безкоштовно, з відкритим кодом, без облікових записів, підписок і телеметрії.

Написано на C# (.NET 9, WPF). Доступ до датчиків — через LibreHardwareMonitor і
драйвер PawnIO; усе інше — сторінки відомостей, тести, звіти й пошук — написано з нуля.

![Огляд](docs/screenshots/overview.png)

## Завантажити

Остання збірка — у [Releases](https://github.com/ifoxp/Silica/releases/latest):

| Файл | Що це |
|---|---|
| `Silica-<версія>-uk.msi` / `-en.msi` | Інсталятор з українським чи англійським майстром. Ставить програму в Program Files і додає її в меню «Пуск». |
| `Silica-<версія>-portable.zip` | Розпакуйте будь-куди й запустіть `Silica.exe`. Нічого не встановлюється. |

Windows 10 або 11, 64-біт. .NET окремо ставити не треба — він уже всередині. Для
температур процесора й датчиків материнської плати один раз встановіть безкоштовний
драйвер [PawnIO](https://pawnio.eu); Silica сама підкаже, якщо його немає.

Windows SmartScreen може попередити про невідомого видавця, бо файли не підписані
сертифікатом. **Докладніше → Виконати однаково** запускає програму.

## Що вміє

- **Усе про залізо й систему.** 28 сторінок: процесор з CPUID і наборами інструкцій,
  материнська плата й BIOS, модулі пам'яті з таймінгами SPD, відеокарта, монітори з
  EDID, диски зі станом і зносом, мережа, звук, пристрої введення й USB, живлення та
  батарея, ОС, процеси, служби, автозапуск, заплановані завдання, програми, драйвери,
  оновлення, безпека (Defender, брандмауер, TPM, BitLocker, VBS), користувачі,
  змінні середовища, спільні папки, шрифти й журнал подій
- **Живі датчики** — температури, частоти, напруги, потужність, вентилятори й
  навантаження з мінімумом, максимумом і середнім, міні-графіками та графіками за кліком
- **Тести продуктивності** — пам'ять (читання, запис, копіювання, затримка), цілочисельні
  обчислення, стиснення, AES, SHA-256, FP32 і FP64, з історією та порівнянням з іншим ПК
- **Тест диска** — послідовна й випадкова швидкість в обхід кешу Windows
- **Тест стабільності** — навантаження на процесор, дробові обчислення, кеш, пам'ять і
  диск, де кожен результат перевіряється, тож нестабільний розгін видно як помилки,
  а не як зависання через годину
- **Тест монітора**, **звіти** (HTML, текст, Markdown, JSON), **значок у треї**,
  **оверлей** поверх вікон, **запис у CSV** і **сповіщення**, коли значення виходить за межу

## Чому вона легка

Програма для моніторингу, яка з'їдає чверть гігабайта, щоб показати, скільки
пам'яті вільно, — поганий жарт. Silica тримають малою три рішення:

**Датчики працюють в окремому процесі.** Бібліотека датчиків і її драйвер займають
нативну пам'ять, яку процес .NET після завантаження вже не може віддати. Тому датчики
живуть у другому `Silica.exe`, з яким вікно говорить через іменований канал. Коли
живі значення хвилину нікому не потрібні — не відкрита сторінка датчиків, немає
значення в треї, оверлею, запису чи сповіщень — цей процес закривається і забирає
свою пам'ять із собою.

**На звичайних екранах інтерфейс малює процесор.** Відеокарта в WPF тримає пристрій
Direct3D і його буфери весь час, поки відкрите вікно, — це близько 50 МБ. До
2560×1600 програмне малювання таке саме плавне, тож воно за замовчуванням; на 4K
вмикається відеокарта. «Налаштування → Вигляд → Відтворення інтерфейсу» змінює це
вручну.

**Нічого не працює, поки на це не дивишся.** Сторінки читаються, коли їх відкривають.
Згорнуте вікно зупиняє таймери й віддає пам'ять Windows.

| | Було | Стало |
|---|---|---|
| Огляд із живими датчиками | 233 МБ | 152 МБ вікно + 123 МБ процес датчиків |
| Сторінка відомостей, датчики звільнено | 228 МБ | 149 МБ, один процес |
| Згорнуте вікно | — | 7–17 МБ |

*Робочий набір, AMD Ryzen 7 7700 + RTX 5070, Windows 11.*

## Пошук, який прощає

Одне поле знаходить сторінки, налаштування, датчики й будь-яке значення на будь-якій
сторінці — одразу всіма встановленими мовами. Зроблено для тих, хто не знає точного слова:

- **помилки й частини слів** — відстань optimal string alignment, тож переставлені
  літери коштують одну правку, а не дві
- **транслітерація** — `videokarta` знаходить «Відеокарта»
- **неправильна розкладка** — `ghjwtcjh`, набране в англійській розкладці, знаходить
  «процесор»; розкладки беруться з установлених у Windows
- **синоніми** — «GPU», «videocard» і «відеокарта» ведуть на одну сторінку

## Мови

Вбудовано 52 мови; при першому запуску Silica бере мову інтерфейсу Windows. Українську
й англійську написано вручну, решту — з допомогою машинного перекладу, тож виправлення
від носіїв мови дуже вітаються. Арабська, іврит і перська відображаються справа наліво,
а числа з одиницями лишаються в правильному порядку. Якщо в мові бракує якогось тексту,
він показується англійською.

Для настрою є три варіанти української — піратська, вікінгська й козацька. Варіант —
звичайний файл мови з полем `"base": "uk"`: формат чисел і все, чого в ньому бракує,
береться з української, а автоматично такі мови ніколи не вибираються.

Нова мова — один файл JSON, без змін у коді: «Налаштування → Мова → Створити шаблон
перекладу», перекладіть значення й покладіть файл у папку мов. Правила для перекладачів —
у [tools/TRANSLATING.md](tools/TRANSLATING.md).

## Права адміністратора

Без них Windows не дає прочитати температури, оберти вентиляторів і стан дисків, тому
Silica просить їх при запуску. Відмовитись можна: програма працює в обмеженому режимі
й запропонує перезапуститись пізніше.

У роботи з правами адміністратора є наслідки, і їх враховано. Файли, папки й посилання
відкриваються через ваш звичайний Провідник, тож браузер, запущений із Silica, не
отримує її прав. «Запускати разом з Windows» створює завдання, яке запускає Silica з
правами адміністратора без запиту, тому воно доступне лише для встановленої копії в
Program Files: портативний `Silica.exe` у «Завантаженнях» могла б підмінити будь-яка
програма.

## Збірка

```powershell
dotnet build Silica.sln                 # налагоджувальна збірка
.\build.ps1 -Version 1.0.0              # портативний zip і обидва інсталятори в .\artifacts
```

Потрібен .NET 9 SDK; скрипт релізу також використовує Python 3 і сам відновлює WiX
як локальний інструмент.

```powershell
Silica.exe --report report.html         # записати звіт без відкриття вікна
Silica.exe --lang uk-x-cossack          # запустити певною мовою
```

```
src/Silica.Core   сторінки відомостей, датчики, тести, звіти (без інтерфейсу)
src/Silica        застосунок WPF
installer         інсталятор WiX
tools             інструменти для мов, генератор значка
```

## Приватність

Silica не виходить в інтернет. Звіти, журнали й результати тестів лишаються на вашому
комп'ютері, поки ви самі ними не поділитесь.
